# Predictotronix guide for players

This guide explains how to join a league, make and change predictions, understand scores, manage reminders and solve common access problems.

## Quick reference

| Task | Where to go |
| --- | --- |
| Join a league | Open the invitation link from your admin |
| Make predictions | **Dashboard**, then browse to a gameweek |
| Save changes | **Save predictions** |
| Remove unsaved/unlocked picks | **Clear predicted scores** |
| Manage reminders | **Dashboard → Notification settings** |
| Use the larger accessible display | The **A** icon in the header |
| Sign out | **Sign out** in the header |

## 1. Join your league

Use the invitation link sent by your league administrator. Do not register separately first unless your admin tells you to; opening the invite preserves the league you are trying to join.

### If you are new to Predictotronix

1. Open the invitation link.
2. Select **Create account and request to join**.
3. Enter a display name, a valid email address and a password of at least 8 characters.
4. Select **Create account and request to join**.
5. If asked, confirm your email using the message sent to you, then sign in.

### If you already have an account

1. Open the invitation link.
2. Select **Sign in to join**.
3. Enter your email and password.

Your request then waits for a league admin. You can close the page; the dashboard will show that approval is pending. Once approved into an active season, the league and its prediction fixtures appear on your dashboard.

An invalid invite cannot be used. Ask your admin for a new link if it has been deactivated or regenerated.

## 2. Find the correct gameweek

After signing in, the dashboard opens the most relevant gameweek automatically. Use **Previous** and **Next** to browse all gameweeks in the active season.

Each gameweek shows:

- its name and first kickoff time in London time;
- how many fixtures you have predicted, such as **8/10 predicted**; and
- every fixture's kickoff, teams and score boxes.

If no active season appears, your join request may still be pending or you may not be enrolled in an active season. Contact your league admin if the dashboard does not explain which applies.

## 3. Make and save predictions

1. Browse to the gameweek you want.
2. Enter the predicted home and away score for each fixture. Scores accept up to two digits.
3. Review your entries.
4. Select **Save predictions**.
5. Wait for the confirmation showing how many predictions were saved.

You can save some fixtures and return for the rest. The completion counter updates after saving.

For a quick starting point, select **Fill with random scores**. It fills only empty, unlocked boxes; review the values and select **Save predictions** yourself.

To remove saved or typed picks for the gameweek, select **Clear predicted scores**, confirm the prompt, and wait for the success message. Only unlocked predictions are cleared.

## 4. Deadlines and locked fixtures

Each fixture locks at its own kickoff time. A fixture marked **LOCKED** cannot be created, changed or cleared by a player. Later fixtures in the same gameweek may remain editable.

Saving early is safest. If you miss a deadline, contact your league admin; only a superadmin can decide whether to enter or amend a prediction on your behalf.

If a superadmin entered a still-editable prediction for you, it is marked **ADMIN-ENTERED**. You can replace it before kickoff by changing the score and saving.

## 5. Results and scoring

After a result is confirmed, the fixture shows the actual score and the points awarded:

- **3 points** for the exact score;
- **1 point** for the correct result (home win, draw or away win); or
- **0 points** for an incorrect result.

The dashboard shows your scored predictions. Competition-wide standings are maintained by the administrators; ask your league admin if you need a published table.

## 6. Notification settings

1. Select **Notification settings** on the dashboard.
2. Choose any combination of:
   - **Email reminders**;
   - **SMS reminders** (requires a mobile number);
   - **Send reminders even when predictions are complete**; or
   - **Opt out of all notifications**.
3. For SMS, enter your mobile number in international format, for example `+447700900000`.
4. Select **Save settings**.

**Opt out of all notifications** overrides the individual reminder choices.

## 7. Display and account controls

- Select the **A** icon in the header to toggle accessible mode. The preference is remembered in that browser.
- Select **Sign out** when using a shared device.
- Your league admin can correct your display name. There is currently no player-facing name editor.

## Troubleshooting

- **My request is pending:** an admin has not approved it yet. You do not need to submit it again.
- **My request was rejected:** contact the league admin; the player interface cannot resubmit a rejected request.
- **The invite is invalid:** ask for a new invitation link.
- **I created an account but cannot sign in:** confirm your email first if the sign-in page asks you to.
- **No active season is shown:** confirm your approval and season enrolment with the league admin.
- **No fixtures are shown:** the admin may not have synced or added them yet.
- **A score box is locked:** its kickoff time has passed; this is expected.
- **My save partly failed:** note the error shown, refresh, check which entries were retained, and contact your admin if it continues.
- **I am not receiving SMS:** save a valid international mobile number, enable SMS, and make sure **Opt out of all notifications** is off.
